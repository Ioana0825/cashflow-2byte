
# CashFlow – Style Guide

**Project:** ASSIST – CashFlow Application
**Version:** 1.0
**Design Concept:** Black & Gold – Premium Finance
**Author:** Cezara
**Status:** Proposed Design

## 1. Visual Identity

Identitatea vizuală a aplicației CashFlow se bazează pe
un stil elegant, minimalist și modern, inspirat de
aplicațiile financiare premium.

Combinația dintre negru și auriu transmite profesionalism,
stabilitate și rafinament.

## 2. Color Palette

| Color | HEX | Purpose |
|---|---|---|
| Black | #121212 | Main background |
| Charcoal | #1E1E1E | Cards and containers |
| Gold | #C6A568 | Primary buttons and accents |
| Champagne | #E8D6B0 | Secondary accents |
| Ivory | #F8F6F1 | Main text |
| Green | #4CAF78 | Income |
| Red | #E57373 | Expenses |

## 4. Logo Design

**Application Name:** CashFlow

Logo-ul va utiliza o combinație între textul CashFlow
și un simbol financiar minimalist, în nuanțe aurii.

Caracteristici:
- Elegant typography
- Gold accents
- Dark background
- Minimalist financial icon

## 5. UI Components

### Buttons

- Primary Button: fundal auriu și text închis.
- Secondary Button: fundal transparent și contur auriu.
- Delete Button: accent roșu.
- Hover Effect: modificare discretă a luminozității.
- Focus State: contur vizibil pentru navigarea cu tastatura.

### Forms

- Fundal închis.
- Contururi discrete.
- Text deschis pentru lizibilitate.
- Mesaje de eroare în roșu.
- Câmpuri și etichete ușor de identificat.

### Cards

- Fundal Charcoal.
- Colțuri ușor rotunjite.
- Contururi subtile.
- Accente aurii pentru informațiile importante.

### Financial Values

- Total Income: Green.
- Total Expenses: Red.
- Current Balance: Gold.

Valorile vor fi însoțite de etichete și semne,
pentru a nu depinde exclusiv de culoare.

## 7. Responsive Design

Interfața va fi adaptată pentru:

- Desktop
- Laptop
- Tablet
- Mobile

Componentele trebuie să rămână lizibile și accesibile
indiferent de dimensiunea ecranului.

## 8. Design Principles

- Consistency
- Simplicity
- Accessibility
- Readability
- Responsive Layout
- Clear Navigation
- Visual Hierarchy

## 9. Implementation

Designul va fi implementat folosind React, Vite și CSS.

Paleta de culori și stilurile comune vor fi definite
centralizat pentru a asigura consistența interfeței.

Acest document reprezintă propunerea de identitate
vizuală pentru aplicația CashFlow și poate fi actualizat
în urma feedbackului echipei.
